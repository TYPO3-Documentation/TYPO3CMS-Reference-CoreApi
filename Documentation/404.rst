`ext_tables.php` no longer loaded
---------------------------------

..  deprecated:: 14.3
    :changelog: deprecation-109438-1774951763

TYPO3 v15 no longer loads the file :file:`ext_tables.php` of an extension.
A registration in it has no effect, and TYPO3 does not report an error.
Move each registration to the file that is meant for it:

*   Backend modules:
    `Configuration/Backend/Modules.php <https://docs.typo3.org/permalink/t3coreapi:extension-configuration-backend-modules>`_
*   Backend routes:
    `Configuration/Backend/Routes.php <https://docs.typo3.org/permalink/t3coreapi:extension-configuration-backend-routes>`_
*   User settings: :file:`Configuration/TCA/Overrides/be_users.php`, see
    `Migration from addFieldsToUserSettings to addUserSetting <https://docs.typo3.org/permalink/t3coreapi:user-settings-extending-migration>`_
*   Record types allowed on a page type:
    :file:`Configuration/TCA/Overrides/pages.php`, see
    `Create a new page type <https://docs.typo3.org/permalink/t3coreapi:page-types-example>`_

An extension that still supports TYPO3 v13 can keep the file for that
version.

..  _abstracttypolinkbuilder-migration:

`AbstractTypolinkBuilder::build()` removed
------------------------------------------

..  deprecated:: 14.0
    :changelog: deprecation-106405-1742674605

TYPO3 v15 removed the method
:php-short:`\TYPO3\CMS\Frontend\Typolink\AbstractTypolinkBuilder::build()`
and the property `$contentObjectRenderer`. A link builder
implements :php-short:`\TYPO3\CMS\Frontend\Typolink\TypolinkBuilderInterface`
and its method `buildLink()`. It gets the content object renderer from the
request attribute `currentContentObject`. See
`Render the custom link format in the frontend <https://docs.typo3.org/permalink/t3coreapi:tutorial-typolink-builder>`_.

`$GLOBALS['TYPO3_USER_SETTINGS']` removed
-----------------------------------------

..  versionchanged:: 15.0
    :changelog: breaking-109783-1776735296

TYPO3 v15 removed the global variable `$GLOBALS['TYPO3_USER_SETTINGS']`,
`deprecated in 14.2 <https://docs.typo3.org/permalink/changelog:deprecation-108843-1738600000>`_.

`ext_emconf.php` no longer evaluated
------------------------------------

..  deprecated:: 14.2
    :changelog: deprecation-108345-1774126701


:file:`ext_emconf.php` files in extensions are no longer evaluated for package
metadata. In TYPO3 classic (non-Composer) mode the :file:`composer.json` must
declare the extension version and the :php:`providesPackages` definition in
the :php:`extra/typo3/cms` section. Both fields are mandatory. An extension
whose :file:`composer.json` lacks them is not registered as a package and is
dropped from :file:`PackageStates.php` during the package scan. No error
message is shown, but TYPO3 writes a warning with the reason to the log file.

Page module section markup events removed
-----------------------------------------

..  deprecated:: 14.3
    :changelog: deprecation-109529-1775733107

The events :php-short:`\TYPO3\CMS\Backend\View\Event\BeforeSectionMarkupGeneratedEvent` and
:php-short:`\TYPO3\CMS\Backend\View\Event\AfterSectionMarkupGeneratedEvent`
were removed with TYPO3 v15. There is no direct replacement so listeners that decorated
backend layout columns with these events should be removed.

..  _ModifyClearCacheActionsEvent-migration-v14:

`CacheAction` "href" key removed
--------------------------------

..  versionchanged:: 14.3
    The `CacheAction` array key `href` used in cache action definitions
    provided via the :php-short:`\TYPO3\CMS\Backend\Backend\Event\ModifyClearCacheActionsEvent`
    has been deprecated in favor of `endpoint`. The new key name better reflects
    the purpose of this field, which is used as an AJAX endpoint URL. The value
    must be a :php:`string`.
